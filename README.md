

# Contact Management System

## Introduction
The Contact Management System is a menu-driven application developed using the C programming language. It helps users manage contact information efficiently.

## Features
- Add new contacts
- Search for contacts
- Update contact details
- Delete contacts
- Sort contacts alphabetically
- Display all contacts
- Save and load contacts using file handling

## Technologies Used
- C Programming Language
- Structures
- Functions
- Arrays
- File Handling

## How to Run
1. Download the source code.
2. Open it in a C compiler.
3. Compile and execute the program.
